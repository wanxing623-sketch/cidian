### 真题库构成

- **2897 道**真题，成语 1436 道 / 实词 1461 道，覆盖 2008–2026 年
- **每道题都带解析**：**2072 道为原题官方解析**，其余 825 道（早年卷、部分市考 / 选调 / 事业单位题，公开源只有题库版解析）按同一体例整理，界面上以「真题官方解析 / 解析」标签区分
- 按**年份**、**成语 / 实词**自由筛选题目；解析中出现的选项词会高亮，点选项里的词可直接跳到该词词卡
- 全部题目经过去重（省考联考卷大量重复，上万条原始记录去重后得 2897 道独立真题），并清除了抓取残留的非逻辑填空题目（数量关系、图形推理、带图题等）

### 解析里的词义（本次重点补全）

- 解析下方逐词列出四个选项的释义，并可直接点开词卡
- 释义来源三层：① 从 2897 道真题解析正文中**反向抽取**（“A项‘xx’指……”这类句式），② 开源词典（现代汉语词语 / 成语），③ 无法自动化覆盖的约 470 个词逐条人工撰写
- 共补入 **5466 条**选项词释义：选项词有释义的比例由 **39% → 96%**，四个选项词全部有释义的题目由 **12% → 85.5%**；剩余多为多空题的短语片段（如“纯洁与高尚”“硬办法”），界面上自动省略，不再显示“—”
