### 真题库构成

- **2161 道**真题，成语 1214 道 / 实词 947 道，覆盖 2009–2026 年
- **每道题都带解析**：2082 道为原题**官方解析**，其余 79 道（早年及部分市考、事业单位题，公开源未收录）按同一体例补写，界面上以「真题官方解析 / 解析」标签区分
- 按**年份**、**成语 / 实词**自由筛选题目；解析中出现的选项词会高亮，点选项里的词可直接跳到该词词卡
- 全部题目经过去重（原始语料里各省联考卷大量重复，6836 条记录去重后得 2082 道独立真题）
